# 보험지기 네이버 블로그 일일 자동 작성 절차

매일 예약 실행(Claude Routine)이 이 문서를 그대로 따른다.
자동 작업은 **원고·이미지 작성과 노션 정리까지만** 한다. 네이버 게시·외부 공유·고객 연락은 하지 않는다.

## 0. 대상 찾기
- 노션 데이터소스: `collection://c75d5f93-b6e6-402e-a324-45b81f3e95c9` (보험지기 SNS 통합 콘텐츠 운영)
- 오늘 날짜(Asia/Seoul) `발행일` 행 중 `채널배포`에 "블로그"가 있고 `상태`가 `주제확정`·`자료확인`·`원고작성`인 행.
- 없으면 아무것도 바꾸지 않고 종료. 이미 `검수대기` 이후 상태면 건너뛴다(중복 작성 금지).

## 1. 규칙 읽기 (매번 노션에서 최신본)
- 보험지기 SNS 통합 운영 가이드 v4: `3ea79506-f3a3-8161-99a7-d64d3b4db7fd`
- 스킬 — 보험지기 블로그 글쓰기 템플릿: `3c279506-f3a3-819e-abb6-cb15318dfbc2`
- 해당 행의 속성(블로그후킹·타겟키워드·서브키워드·핵심질문·자료수집가이드·근거출처·CTA문구·내부링크계획·썸네일문구)과 본문 기획안.

## 2. 원고 작성
- 템플릿 16단계 + v4 "블로그 전개 속도"(도입 2문단 안에 결론 일부) 준수, 2,500~4,000자.
- 법령·세율·한도는 단정하지 말고 근거 기관명을 밝히며, 확인 못 한 수치는 넣지 않는다.
- 원고 안에 `[이미지 ① 타이틀]`, `[이미지 ② 서브1]`, `[이미지 ③ 서브2]`, `[이미지 ④ 서브3]` 위치 표시.
- 고정 CTA는 v4 가이드의 연락처를 사용.

## 3. 이미지 4장 만들기
1. `blog_images/output/<YYYY-MM-DD>/spec.json` 작성 (형식은 `blog_images/example.json`).
   - title: kicker(인스타3초후킹 등), headline(썸네일문구), headline_html(강조 단어를 `<em>`), sub
   - subs 3개: type은 `cards`(4개 카드) / `table`(첫 행 헤더) / `check` / `list` 중 원고 흐름에 맞게
2. `node blog_images/render.mjs blog_images/output/<날짜>/spec.json blog_images/output/<날짜>`
3. PNG 4장을 Read로 열어 글자 넘침·잘림이 없는지 확인. 넘치면 문구를 줄여 다시 렌더링.

## 4. 이미지를 노션에 올리기
이 환경에서는 api.notion.com 직접 업로드가 막혀 있으므로 공개 저장소의 raw URL을 쓴다.
1. `blog_images/output/<날짜>/`를 커밋하고 이 세션이 푸시할 수 있는 브랜치에 푸시.
2. `https://raw.githubusercontent.com/calmgrou7/chaeum/<커밋SHA>/blog_images/output/<날짜>/<파일>.png`가 200인지 curl로 확인.
3. Notion `create-attachment`에 `source_url`로 4장 업로드 → 받은 `file-upload://...`로 바로(1시간 안에) 페이지에 삽입.

## 5. 노션 정리
- 해당 행 페이지 **끝에 추가**(기존 기획안은 그대로 둔다): 검수 안내 콜아웃 → 이미지 4장(용도 설명 포함) → 원고 → FAQ → 해시태그.
- `상태`를 `검수대기`로 변경. `근거상태`는 공식자료를 실제로 확인했을 때만 `확인완료`로 바꾼다.
